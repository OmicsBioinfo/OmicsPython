# Identificador de Genes de Resistencia (100% de similitud)

Este proyecto bioinformático, creado con Python, tiene la funcionalidad de generar reportes
con tablas, donde se visualizan los genes de resistencia que se encuentran en pacientes, cuyas
secuencias han sido analizadas previamente y se ingresan en formato fasta. En la base de datos
local del proyecto se han incluido más de 6000 genes de resistencia. Solo se incluyen los resultados 
que coinciden plenamente al 100%. 

---

##**Características**
El proyecto fue escrito en el lenguaje de programación Python, usando distintas librerias para darle 
funcionalidad al proyecto. También incorpora algo de HTML para crear los reportes de genes de resistencia
encontrados en las secuencias nucleotídicas de pacientes.
